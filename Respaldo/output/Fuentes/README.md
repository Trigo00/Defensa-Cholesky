# Fuentes externas del proyecto Cholesky

| ID | Fuente y enlace | Qué tomamos de la fuente |
|---|---|---|
| F01 | Grey Ballard, James Demmel, Olga Holtz y Oded Schwartz (2009), **Communication-optimal Parallel and Sequential Cholesky Decomposition**. [PDF original, LAPACK Working Note 215](https://www.netlib.org/lapack/lawnspdf/lawn215.pdf). | Fundamentos de Cholesky, variantes left-looking y right-looking, movimiento de datos y modelo de costos de comunicación por latencia y volumen. |
| F02 | Netlib, **Cholesky Factorization**. [Página original](https://www.netlib.org/utk/papers/factor/node9.html). | Organización right-looking: factorización del panel, actualización de la matriz restante y dependencias entre esas operaciones. |
| F03 | **ScaLAPACK Users' Guide: The Two-dimensional Block-Cyclic Distribution**. [Sección original](https://www.netlib.org/scalapack/slug/node75.html); [guía completa](https://www.netlib.org/scalapack/slug/). | Conceptos de reparto por bloques, cíclico y por bloques cíclicos, y su relación con el equilibrio del trabajo y el acceso a memoria. |
| F04 | **ScaLAPACK Users' Guide: Local Storage Scheme and Block-Cyclic Mapping**. [Sección original](https://www.netlib.org/scalapack/slug/node76.html). | Mapeo entre índices globales y locales, identificación del proceso dueño y almacenamiento compacto de sus datos. |
| F05 | Joseph Dorris, Jakub Kurzak, Piotr Luszczek, Asim YarKhan y Jack Dongarra, **Task-Based Cholesky Decomposition on Knights Corner Using OpenMP**. [PDF original](https://netlib.org/utk/people/JackDongarra/PAPERS/task-based-cholesky.pdf). | Dependencias entre tareas y planificación dinámica, como alternativa conceptual al reparto estático de columnas. |
| F06 | Open MPI, **MPI_Bcast**. [Manual oficial](https://docs.open-mpi.org/en/main/man-openmpi/man3/MPI_Bcast.3.html). | Difusión de la columna activa desde el proceso dueño hacia todos los procesos del comunicador. |
| F07 | Open MPI, **MPI_Wtime**. [Manual oficial](https://docs.open-mpi.org/en/main/man-openmpi/man3/MPI_Wtime.3.html). | Medición del tiempo transcurrido en segundos y carácter local del reloj de cada proceso. |
| F08 | LAPACK/Netlib, **DPOTRF**. [Fuente Fortran](https://www.netlib.org/lapack/double/dpotrf.f); [documentación de DPOTRF 3.12.1](https://www.netlib.org/lapack/explore-html/d2/d09/group__potrf_ga84e90859b02139934b166e579dd211d4.html). | Factorización de matrices simétricas definidas positivas, selección del triángulo, códigos de error y organización por bloques con BLAS de nivel 3. |
| F09 | **OpenMP Application Programming Interface, Version 5.2** (noviembre de 2021). [Especificación HTML](https://www.openmp.org/spec-html/5.2/openmp.html); [PDF oficial completo](https://www.openmp.org/wp-content/uploads/OpenMP-API-Specification-5-2.pdf). | Referencia para futuras versiones con paralelismo de memoria compartida y una combinación de MPI con hilos. |
| F10 | Netlib, **The LAPACKE C Interface to LAPACK**. [Manual oficial](https://www.netlib.org/lapack/lapacke.html). | Uso de LAPACK desde C mediante la interfaz `_work`, almacenamiento por columnas y eliminación de la transposición y del barrido opcional de NaN de la interfaz de alto nivel. |
| F11 | OpenBLAS, **Extensions** y **Usage**. [API oficial de extensiones](https://www.openmathlib.org/OpenBLAS/docs/extensions/); [manual oficial de uso](https://github.com/OpenMathLib/OpenBLAS/blob/develop/USAGE.md). | Configuración de OpenBLAS con un hilo y consulta de la cantidad efectiva de hilos y de la configuración de la biblioteca. |
| F12 | MPI Forum, **MPI: A Message-Passing Interface Standard, Version 5.0** (5 de junio de 2025). [PDF oficial](https://www.mpi-forum.org/docs/mpi-5.0/mpi50-report.pdf); [copia local](../mpi50-report.pdf). | Referencia general para comunicadores, tipos de datos, operaciones colectivas y temporización en MPI. |
| F13 | Mark Gates et al., **SLATE Users' Guide** (7 de julio de 2020), ICL-UTK-1390-2020. [PDF original](https://icl.utk.edu/files/publications/2020/icl-utk-1390-2020.pdf); [copia local](../icl-utk-1390-2020.pdf). | Antecedente sobre bibliotecas de álgebra lineal distribuida y cálculo por bloques para posibles extensiones del proyecto. |
