# Proyecto Cholesky

El material está separado en dos carpetas:

- [Defensa](Defensa/LEEME.md): programa final, documento principal y comandos sencillos para ejecutar y comparar tiempos. Esta es la carpeta de trabajo para preparar la exposición.
- [Respaldo](Respaldo/README.md): proyecto técnico completo, experimentos, mediciones, pruebas y herramientas de verificación.

Para ejecutar el programa final, abrí una terminal Linux/WSL dentro de `Defensa` y seguí [COMANDOS.md](Defensa/COMANDOS.md).

Para reproducir las campañas o verificar la evidencia, abrí la terminal dentro de `Respaldo`. Sus rutas internas se conservaron: por ejemplo, `python3 scripts/analyze_results.py` y `python3 tests/validation/verify_delivery.py` se ejecutan desde esa carpeta.

El documento principal y los cinco fuentes en Defensa son copias del material conservado en Respaldo. Si se editan después, las dos carpetas no se sincronizan automáticamente.
